# NodOrder Processed Dataset Directory
이 디렉터리는 `featureExtractor.js`를 통해 정규화 및 가공된 특징 벡터(Feature Vector) 데이터셋을 보관하는 곳입니다.

## 특징 벡터 스키마 (4차원)
1. `noseDeltaX`: 캘리브레이션 기준점 대비 코의 X축 상대 변화량 (안구 간격 정규화 적용)
   - 중립 영역: -0.150 ~ +0.150 (복귀: ±0.080)
   - 음수 (-): 사용자의 왼쪽으로 고개 회전 (좌측 이동)
   - 양수 (+): 사용자의 오른쪽으로 고개 회전 (우측 이동)
2. `noseDeltaY`: 캘리브레이션 기준점 대비 코의 Y축 상대 변화량 (안구 간격 정규화 적용)
   - 중립 영역: -0.120 ~ +0.140 (복귀: ±0.060)
   - 음수 (-): 고개 들림 (위)
   - 양수 (+): 고개 숙임 (끄덕임)
3. `headTiltDeg`: 두 눈 기준 상대 머리 기울기 각도 (Roll 각도, 도 단위)
   - 중립 영역: -8.00° ~ +8.00° (복귀: ±4.00°)
   - 음수 (-): 반시계 방향 기울임 (사용자의 왼쪽 기울임 / 이전 단계)
   - 양수 (+): 시계 방향 기울임 (사용자의 오른쪽 기울임 / 다음 단계)
4. `mouthOpenRatio`: 입 벌림 종횡비 (MAR, Mouth Aspect Ratio)
   - 0.02 ~ 0.08: 구강 폐쇄 (CLOSED)
   - 0.25 이상: 구강 개방 (OPEN)

## 오작동 방지 표준 파라미터 (`GESTURE_CONFIG`)
- 노이즈 완화 계수: EMA $\alpha = 0.35$
- 지속 시간 조건 (Dwell Time): 최소 $350\text{ ms}$ 유지 시 발동
- 히스테리시스 락: 1회 발동 후 중립 복귀 임계값 이내로 복귀해야 재장전

## 통합 데이터셋 구성
- `train.json`: 학습용 참가자군(예: P01, P02, P03) 데이터
- `test.json`: 평가용 독립 참가자군(예: P04, P05) 데이터 (Leave-One-Subject-Out 또는 Subject-Independent 검증)
